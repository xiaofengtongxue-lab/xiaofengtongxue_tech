# Java 技术教程

本栏目面向 Java 服务端开发者，围绕真实项目结构、Spring Boot、数据库、并发、异常处理、测试和部署整理可复用的工程实践。

## 计划内容

- Java 项目结构和构建工具
- Spring Boot 启动与配置体系
- Controller、Service 和数据访问边界
- 统一异常处理与错误响应
- 事务、并发与数据一致性
- 单元测试和集成测试
- JVM 问题定位与性能分析

跨语言通用的测试、Git 和部署内容会统一放在 [工程实践](/engineering/)。
