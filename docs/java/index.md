# Java 技术教程

哈喽，我是小枫同学 👋 欢迎来到我的 Java 技术小窝！

这个栏目是我日常搬砖的实战笔记，主要面向 Java 服务端开发。我踩过的坑、复盘过的项目、反复用到的套路，都会整理在这里，希望能帮你少走点弯路。

## 打算写这些

- Java 项目怎么搭，构建工具怎么选
- Spring Boot 启动流程和配置那一套东西
- Controller、Service、数据访问层怎么划分职责
- 统一异常处理，别再到处 try-catch 了
- 事务、并发、数据一致性这些让人头大的话题
- 单元测试和集成测试怎么写才不糊弄
- JVM 问题定位和性能调优的实战思路

跨语言的通用内容——测试、Git、CI/CD 部署这些——我都归到了 [工程实践](/engineering/) 里，那里更偏方法论，不会跟具体语言绑得太死。
