# 开发工具教程

嘿，欢迎光临我的工具间 👋

这一亩三分地里，我主要折腾各种开发工具的"疑难杂症"——怎么装、怎么配、怎么把它们拧成一股绳干活，以及踩了坑怎么爬出来。每篇文章我都会附上验证方法，确保你不是光看个热闹，而是能真正跑通。

## 打算写点什么

- **Git 与 GitHub 工作流**：提交、分支、PR，还有那些让人挠头的 merge/rebase 问题
- **IDE、编辑器与代码格式化**：VS Code、JetBrains 这些家伙的配置和插件，格式统一不再打架
- **终端、Shell 和环境变量**：让命令行顺手起来，PATH 乱了也知道怎么救
- **HTTP、数据库和日志调试工具**：curl、postman、数据库客户端、日志查错三板斧
- **MCP 服务的安装与权限边界**：怎么装上 MCP，又怎么不让它乱跑
- **AI 编程工具的能力和适用场景**：哪些活扔给 AI 省心，哪些还得自己撸袖子

> 💡 关于 Codex 的专门内容，我都整理到 [Codex 教程](/codex/) 那边了，这边就不重复了哈。

有什么工具搞不定的，欢迎随时来翻翻——我也在边学边记，一起进步 😄
