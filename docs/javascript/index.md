# JavaScript 与 TypeScript 教程

哈喽，我是小枫同学！这个专栏是我在 JS 和 TS 这条路上摸爬滚打的真实记录。

不管你是写浏览器端页面还是搞 Node.js 服务，这里聊的东西都挺贴近实际开发的——从类型系统怎么用才顺手，到异步代码怎么写不踩坑，再到项目结构怎么搭才不后期翻车，我都会一点点整理出来。

## 计划内容

- JavaScript 运行机制和异步模型——到底 event loop 在忙啥
- TypeScript 类型设计与项目配置——别让类型变成负担
- Node.js 服务端项目结构——目录怎么分才清晰
- 包管理、构建和依赖治理——node_modules 黑洞求生指南
- 接口请求、状态管理和错误处理——跟后端打交道的那点事
- 前端测试与性能优化——让页面快起来、稳得住

关于通用的代码审查、测试策略和部署流程，我都放在 [工程实践](/engineering/) 那边了，两边配合着看效果更好。
