# 软件工程实践

本栏目整理不局限于某种编程语言的软件工程方法，帮助开发者把代码变成可测试、可审查、可部署和可维护的系统。

## 核心主题

- Git 分支、提交和代码审查
- 单元测试、集成测试和端到端测试
- API 设计与错误处理
- 数据库迁移和数据一致性
- 配置、密钥和环境隔离
- 部署、日志、监控和故障排查
- 性能分析与容量评估

具体语言实现分别放在 [Java](/java/)、[JavaScript / TypeScript](/javascript/) 和 [Go](/go/) 栏目。
