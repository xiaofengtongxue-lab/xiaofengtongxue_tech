# 软件工程实践

嘿，欢迎来到我的软件工程小角落！👋

写代码久了就发现一个事儿——语言只是工具，真正让项目活下来、不翻车的，其实是那些"跨语言"的工程习惯。这个栏目就是我平时踩坑、复盘、整理出来的一些方法，不绑定某门语言，纯粹聊怎么把代码写得靠谱一点。

## 我常琢磨的几个方向

- Git 分支怎么管、commit 怎么写、code review 怎么看
- 单元测试、集成测试、端到端测试——到底该写哪种、写到什么程度
- API 怎么设计才不坑队友、错误处理怎么搞才不丢信息
- 数据库迁移那点事：改表不改命，数据一致性怎么兜底
- 配置、密钥和环境隔离——别让生产事故从配置文件里溜进去
- 部署、日志、监控、排障：出了问题你得知道从哪下手
- 性能分析和容量评估：别等用户投诉才想起来看指标

每种语言有自己的实现套路，具体代码我会放在对应栏目里：[Java](/java/)、[JavaScript / TypeScript](/javascript/) 和 [Go](/go/)，各回各家，这里只聊通用的工程思路。

希望这些笔记对你有用，也欢迎一起讨论——毕竟工程这件事，永远有更好的做法。😄
