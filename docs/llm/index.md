# 大模型技术教程

本栏目面向大模型应用开发者，目标是把常见概念、系统边界和工程取舍讲清楚，并提供可以验证的实现路径。

## 核心主题

- Token、上下文窗口和提示长度
- 推理模型与普通生成模型
- Tool Calling 和结构化输出
- Embedding、检索与 RAG
- 模型接口、流式输出和错误处理
- 大模型应用的评测、成本与可靠性

## 内容原则

涉及模型能力、参数、价格、限制和版本变化时，以当前官方资料和实际验证结果为准，并在文章中记录验证日期。
