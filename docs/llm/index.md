# 大模型技术教程

嗨，我是小枫同学，欢迎来逛我的大模型笔记 👋

说实话，大模型这块东西更新太快了，我自己也在一边踩坑一边学。这个栏目的初衷很简单：把我折腾 LLM 应用开发过程中搞明白的那些概念、踩过的坑、做过的取舍，用最直白的话整理出来。不讲玄学，尽量每一条结论你都能自己复现验证。
