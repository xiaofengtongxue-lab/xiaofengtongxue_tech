# 嗨，我是小枫同学 👋

一个喜欢折腾技术、更乐意把踩坑经验分享出来的程序员。你可能在公众号上见过我，或者无意间搜到了这个站点——不管咋来的，先握个手 🤝

这个站就是我写教程、做笔记的地方。面向普通打工人、开发者和技术团队，整理 AI 编程、AI Agent、编程语言和软件工程方面的实操内容。不写玄乎的概念，只聊能跑起来的东西。

## 我在这里写什么

我不太关心某个工具能"一键生成"多少东西——我更在意你拿到一个问题之后，怎么理解它、怎么选方案、怎么验证结果，最后稳稳地交付出去。

- **AI 编程 & AI Agent**：模型怎么用、上下文怎么给、工具调用、MCP、Skill、工作流和评测；
- **Codex 实战**：从日常办公到写代码、做自动化，权限和团队协作怎么搞；
- **软件工程**：编程语言、架构、数据库、调试、测试、性能、安全和部署；
- **技术判断**：信哪个源、选哪条路、边界在哪、翻车了怎么救。

Codex 是我用来讲 Agent 概念和工程工作流的一个案例工具，不代表这个站的全部——以后还会有更多方向。

## 内容是怎么写的

工具的行为、命令、参数、版本这些东西说变就变，我会优先翻官方文档、官方仓库或者自己跑一遍确认。教程里的命令、路径和示例，都尽量给你预期结果和验证方法；我没法亲自验证的地方，会老老实实标出来，不把猜测当结论。

安全方面：本站绝不会让你公开真实的 API Key、密码、Cookie 或 Token。涉及发送、发布、付款、删除、生产数据和高权限操作时，教程会明确提醒你：动手之前先想清楚。
