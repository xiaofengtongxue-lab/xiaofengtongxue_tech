# 关于程序员小枫同学

“程序员小枫同学”是本站与同名公众号统一使用的公开名称。这里面向普通工作者、开发者和技术团队，持续整理 AI 编程、AI Agent、编程语言与软件工程实操教程。

## 这里发布什么

本站关注的不是某一个工具能生成多少内容，而是读者怎样理解问题、选择方法、控制权限、验证结果，并完成可靠交付。

- AI 编程与 AI Agent：模型、上下文、工具调用、MCP、Skill、工作流和评测；
- Codex 实战：普通工作任务、代码项目、自动化、权限与团队协作；
- 软件工程：编程语言、架构、数据库、调试、测试、性能、安全和部署；
- 技术判断：事实来源、方案取舍、风险边界、验证方法和失败恢复。

Codex 是当前用于讲解 Agent 概念和工程工作流的具体案例之一，不是本站的全部范围。

## 内容怎样完成

可能变化的产品行为、命令、参数和版本信息优先核对官方文档、官方仓库或实际运行结果。教程中的命令、路径和示例会尽量提供预期结果与验证方法；无法验证的部分会明确标注，不把推测写成事实。

本站不会要求读者公开真实 API Key、密码、Cookie 或 Token。涉及发送、发布、付款、删除、生产数据和高权限操作时，教程会保留人工确认边界。
