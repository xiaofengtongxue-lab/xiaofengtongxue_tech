# 普通人如何整理 ChatGPT 项目、任务和本地文件

普通用户最容易卡住的不是提示词，而是不知道应该上传一个文件、创建一个项目，还是授权整个文件夹。本章不讲开发术语，用“资料柜”和“工作单”建立一套安全的文件组织方式。

## 先记住四个概念

| 概念 | 日常类比 | 什么时候用 |
| --- | --- | --- |
| 项目 | 一个长期资料柜 | 同一客户、活动、课程或研究会持续多次任务 |
| 任务 | 一张只交付一个结果的工作单 | 一份 PPT、一次分析、一封邮件草稿 |
| 附件 | 随当前工作单附上的资料 | 只在这次任务中需要的文档、表格、图片 |
| 本地项目 | 授权应用使用电脑中的一个文件夹 | 多次任务都要读取或更新同一批本地文件 |

项目保存共同背景，任务保持单个结果聚焦。把“市场研究、制作 PPT、写发布稿、发送邮件”全部塞进一个任务，通常会让资料、版本和审批混在一起。

## 什么时候不用创建项目

以下任务直接选择 **New task** 即可：

- 把一次会议记录整理成行动清单；
- 比较两份报价；
- 根据一份简历起草面试问题；
- 把一篇文章改成三个标题版本；
- 从一个 PDF 提取表格。

判断标准：完成后你大概率不会继续沿用同一批资料，也不需要让后续任务记住背景。

## 什么时候应该创建项目

以下情况适合项目：

- 一个新品从研究、定位、详情页到复盘会持续数周；
- 每周都要根据同一套数据生成经营简报；
- 一门课程要持续制作讲义、PPT、练习和答疑；
- 一部漫剧要长期共享角色设定、分镜和素材；
- 同一个客户会产生多份提案、合同草稿和会议纪要。

项目名应该能让未来的你看懂，例如“2026 夏季新品试用活动”，不要使用“新项目 3”。

## 附件和本地项目怎样选

只需要两三个明确文件时，优先附加文件。只有在以下情况才考虑本地项目：

- 文件数量较多，反复手动选择容易漏；
- 后续任务需要在同一个文件夹持续创建或修改文件；
- 你清楚这个文件夹里有什么，并愿意让任务访问；
- 已经建立专门的工作副本，不是整个桌面或个人文档根目录。

不要因为省一次选择文件，就授权“桌面”“下载”或整个“文档”目录。

## 用 Finder 或文件资源管理器准备安全工作区

新建一个专门文件夹，例如：

```text
新品试用活动-AI工作区
├── 01-原始资料-只读
├── 02-工作副本
├── 03-AI输出待审核
└── 04-人工确认可交付
```

这只是文件夹示意，不需要输入任何命令。

### 01-原始资料-只读

放经过筛选的资料副本。保留原始版本用于对照，不让任务覆盖。

### 02-工作副本

放允许整理、清洗或改写的文件。文件名标明日期和版本。

### 03-AI输出待审核

所有新生成文件先进入这里。这里的内容不能直接对外发送。

### 04-人工确认可交付

只有经过事实、格式、隐私和业务审核的文件才能移动到这里。

## 授权文件夹前做五项检查

1. 删除真实密码、API Key、Cookie、身份证、银行卡等凭证和身份信息；
2. 把客户姓名、手机号、地址替换成明确占位符；
3. 删除与当前任务无关的私人照片、聊天导出和其他项目资料；
4. 确认文件夹里没有唯一原件；
5. 打开文件列表，确保每一项都愿意被当前任务读取。

如果你无法确认，就不要授权文件夹，只附加必要文件。

## 一个项目里怎样拆任务

以电商新品为例：

1. 任务一：整理产品事实表；
2. 任务二：完成有来源的竞品研究；
3. 任务三：制作三种定位方案；
4. 任务四：生成商品页草稿；
5. 任务五：制作运营复盘表格。

每个任务只产生一种主要结果。相关任务放在同一项目里共享资料，但不要让一个无限延长的任务承担所有工作。

## 文件命名让你保留控制权

推荐：

```text
客户访谈总结-2026-07-11-v1.docx
客户访谈总结-2026-07-11-v2-已核数字.docx
客户访谈总结-2026-07-11-final-待发送.docx
```

避免：

```text
最终版.docx
最终版2.docx
真的最终版.docx
```

“final”只代表内容已经人工确认，不代表已经发送或发布。

## 长期项目的维护习惯

- 一个任务完成后改成描述结果的名称；
- 经常返回的项目或任务可以固定；
- 已完成任务归档，不要删除仍需追溯的记录；
- 新资料到来时注明日期和来源；
- 过期规则及时更新，避免后续任务继续使用旧价格、旧政策或旧模板；
- 不再需要本地文件夹访问时，移除项目或收紧授权。

## 常见失败

### 为了方便授权整个电脑文档目录

风险是无关文件、私人资料和其他客户信息进入任务范围。建立专用副本文件夹，只授权当前工作需要的内容。

### 所有工作放在一个任务里

任务越来越长后，目标、版本和审批点会混乱。按“一次交付一个结果”拆分，项目负责共享背景。

### 原始文件和生成文件混在一起

至少分开“原始资料”和“AI 输出待审核”。没有人工确认前，不覆盖来源文件。

### 以为固定项目会增加访问权限

固定只改变侧边栏位置，不会自动增加上下文或权限。你仍需要明确附加资料或授权文件夹。

## 完成门槛

- [ ] 能说清项目、任务、附件和本地项目的区别。
- [ ] 有一个只包含任务资料的安全副本文件夹。
- [ ] 原始资料、工作副本、待审核输出和可交付文件分开。
- [ ] 每个任务只定义一个主要成品。
- [ ] 文件名包含主题、日期和版本。
- [ ] 没有授权整个桌面、下载或个人文档目录。
