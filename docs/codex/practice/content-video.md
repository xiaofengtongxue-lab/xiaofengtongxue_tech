# 用 Codex 制作图文、短视频和内容素材

内容生产的效率瓶颈通常不在“写第一稿”，而在事实、结构、素材版本、尺寸变体和发布检查。本页用一场新品试用活动的图文与 60 秒短视频改编，建立可复用内容生产线。

## 不会写代码怎样完成本章

普通创作者可以用 ChatGPT Work 整理事实、生成各渠道结构、制作文案和分镜，再使用 Canva、剪映、CapCut 或熟悉的设计剪辑软件完成成品。Markdown、HTML、Remotion 和批量脚本都是可选增强，不是入门前提。

先把任务限制为“生成草稿和预览”，发布、定时、广告预算和账号操作全部由人确认。第一次实践可以从一篇图文和一条 60 秒视频开始。

## 第一步：建立事实包

`source-pack.md`：

```md
# 主题
新品试用活动怎样报名

# 受众
第一次了解活动的老客户

# 必须事实
- 报名开放 100 个名额
- 报名页计划 7 月 18 日上线
- 最终优惠额度和客服值班时间尚未确认

# 禁止
- 不承诺一定获得名额或尚未批准的优惠
- 不展示真实客户姓名、联系方式或后台账号
- 不复制其他教程的标题、段落和比喻

# 来源
- 已批准的活动方案
- 产品事实表和客服确认记录
```

只有事实包通过，后续图文和视频才能保持一致。

## 第二步：为不同渠道分别设计结构

不要把长文机械裁成短句。

### 公众号/博客

问题 → 常见错误 → 完整步骤 → 示例 → 验证清单。

### 小红书/轮播卡片

封面承诺 → 3-6 个关键步骤 → 错误示例 → 一页清单 → 延伸阅读。

### 60 秒短视频

0-3 秒问题钩子 → 3-45 秒三个动作 → 45-55 秒验证 → 55-60 秒总结。

提示：

```text
基于 source-pack.md，分别设计博客、8 页轮播卡片和 60 秒视频的内容结构。三者事实一致，但不要逐句复用。先输出结构和每一部分的传播目标，不写成稿。
```

## 第三步：完成原创写作

```text
写博客正文。开头直接回答读者会得到什么；活动日期、名额、规则和未确认信息保持精确；使用自己的结构和例子；每个步骤包含预期结果与失败处理。不要沿用来源的标题顺序和标志性表达。
```

然后做“来源脱敏”检查：

- 结构是否独立；
- 句式和比喻是否明显相似；
- 是否出现连续长段近似表达；
- 引用是否必要且足够短；
- 事实链接是否保留。

## 第四步：生成轮播卡片

可使用 Canva、Figma、社交卡片 Skill 或 HTML→PNG 工作流。

```text
把已确认内容制作成 8 页 3:4 轮播卡片。

要求：
- 每页一个信息点；
- 封面不使用焦虑、夸张收益和绝对承诺；
- 日期、步骤和行动按钮清楚可读；
- 正文字号适合手机；
- 统一页码和品牌；
- 生成后拼接 contact sheet 检查节奏和重复；
- 不发布。
```

除了逐页查看，还要缩略图查看整组：颜色是否单调、页面是否全是同一布局、重点是否清楚。

## 第五步：生成视频脚本和分镜

```text
把内容改编为 60 秒竖屏说明视频。输出 timecode、旁白、画面、屏幕文字、素材和转场。旁白使用自然口语，屏幕文字只保留关键词。涉及报名页面和客户反馈的画面必须使用脱敏演示素材。
```

先读出旁白计时。60 秒中文旁白通常需要按实际语速调整，不要只按字数猜。

## 第六步：制作画面与录屏

素材优先级：

1. 自己录制的脱敏操作；
2. 自有截图和图表；
3. 经过授权的品牌资产；
4. AI 生成的说明性插图；
5. 有明确商业许可的素材库。

AI 图不应用来伪造真实产品效果、数据、用户评价或操作结果。

## 第七步：配音、字幕和剪辑

Remotion、HeyGen 或视频工具可以帮助组装。要求：

```text
按 storyboard.csv 生成 1080x1920、30fps 预览视频。字幕使用最终旁白的真实时间码，保留底部安全区。只用已批准素材和音乐。输出预览 mp4、srt 和素材 manifest，不上传平台。
```

真人/克隆声音和数字人需要明确授权。平台要求标注 AI 内容时按当前规则执行。

## 第八步：多尺寸变体

不要简单裁切：

- 9:16：短视频主版；
- 1:1：信息流方图；
- 16:9：横版视频/封面；
- 3:4：轮播卡片；
- 2.35:1 或平台特定比例：公众号封面。

每个比例重新检查安全区、文字、人物和构图。Canva Resize 或受控模板 Skill 可以提高效率，但仍需逐版本 QA。

## 第九步：发布前检查

### 事实

- 日期、名额、规则、数字和链接正确；
- 演示结果与真实操作一致；
- 没有夸大收益和绝对结论。

### 版权与隐私

- 素材、音乐、字体、Logo 和肖像有权使用；
- 录屏没有账号、通知、路径、Token 和用户数据；
- AI 生成内容按平台要求披露。

### 技术

- 分辨率、编码、时长、音量、字幕和封面正确；
- 手机上文字可读；
- 链接和二维码在目标渠道可用。

### 发布

- 标题、简介和标签不误导；
- 评论/客服预案就绪；
- 发布、定时和广告预算由人确认。

## 第十步：把稳定流程做成 Skill

当同一套事实包 → 多渠道结构 → 素材 → QA 连续成功后，创建自己的 Skill，固定输入目录、输出命名、尺寸表和检查表。不要把某篇文章的内容写死在 Skill 里，Skill 应描述方法。

## 常见失败

### 同一文案复制到所有渠道

保持事实一致，结构和节奏按渠道重做。

### 卡片文字太多

每页一个结论，长解释回到正文链接。

### 视频配音和字幕不同步

先锁最终音频，再生成时间码。

### 自动发布未经检查

默认生成草稿和预览，外部发布必须人工批准。

## 完成门槛

- [ ] 事实包和来源已确认。
- [ ] 各渠道结构独立，不机械复制。
- [ ] 图文和视频都经过真实渲染检查。
- [ ] 素材、字体、音乐和肖像有授权。
- [ ] 录屏和文件已脱敏。
- [ ] 发布、投放和预算由人批准。
