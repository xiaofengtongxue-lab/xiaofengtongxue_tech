# ChatGPT Work 与 Codex 场景实战

嘿，朋友！欢迎来到这个实战栏目。不管你是写周报写到头秃的职场人、刚接到"做个 PPT"任务的运营同学，还是想用 AI 提速的开发者——这里都有你能直接上手的东西。

先说句大实话：我当初刚接触这些工具的时候，也踩过一堆坑。比如让 AI 直接"帮我做个 PPT"，结果它给我生成了一堆看起来像 PPT 但实际上打不开的玩意儿，白白浪费一个下午。后来慢慢摸索出一套方法，才真正让 AI 变成了靠谱的生产力搭档。这个栏目就是把这些经验整理出来，帮你少走弯路。

如果你还不太熟上传文件、预览成品、设置审批边界这些基础操作，建议先去瞄一眼 [普通人完整学习路线](/codex/everyday/)，花十来分钟就能搞定。

## 先选正确入口

不同任务用不同工具，这事挺重要的。我见过不少朋友在 ChatGPT 对话框里死磕代码，或者在 Codex 里让 AI 帮忙改 PPT 文案——都能干，但效率差很多。简单说就是这样：

| 任务 | 推荐入口 | 是否需要编程 |
| --- | --- | --- |
| 快速改写、解释或头脑风暴 | Chat | 不需要 |
| PPT、报告、表格、研究和内容成品 | ChatGPT Work | 不需要 |
| 网站、程序、脚本和技术系统 | Codex | 不要求你亲自写代码，但需要检查技术结果 |

目前的官方说明是：已经在用 Codex 做非编程工作的同学可以继续用，也可以切到更适合日常工作的 Work。这个页面里讲的方法两个都适用——出现终端、代码或脚本的时候，我会明确标成"开发者增强选项"，普通用户跳过就行。

## 先建立一个通用生产模型

不管你要做 PPT、商品页还是漫剧，我都建议按这六步来。这是我踩坑踩出来的血泪经验——跳过哪一步都可能翻车：

1. **定义交付物**：文件类型、受众、尺寸、渠道和完成标准。
2. **整理可信输入**：事实、数据、素材、品牌规范和禁止事项。
3. **先产结构**：大纲、信息架构、分镜或数据分析计划。
4. **分批生成**：每一批都有可检查的中间产物。
5. **渲染与验证**：打开真实文件/页面/视频检查，不只读文本报告。
6. **人工批准外部动作**：发送、分享、上架、投放、发布和付款。

这里面第 5 步和第 6 步是我自己翻过车的点，值得多说一句。第 5 步——AI 吐出来的文件，光看它的文字描述"已经生成好了"是不够的，你必须亲自打开看一眼。我有次让 AI 生成了一个 Excel，它告诉我"包含三个 sheet，数据完整"，我差点就直接发出去了。幸亏打开看了一眼——里面全是占位符。第 6 步更关键：自动化工具能帮你把草稿一键发出去，但草稿就是草稿，发出去就是事故了。发邮件、上架商品、推送到生产环境之前，人必须过一遍。

## 选择 Skill 和 Plugin 的原则

聊到 Skill 和 Plugin，我刚开始也是一通乱装，结果工作区乱得不行。后来总结了几条原则，现在装任何新东西之前都会过一遍：

普通用户先去桌面应用的 Skills 或 Plugins 列表里看看当前有哪些可用的。输入框里也能选：ChatGPT / Work 一般用 `@` 选 Plugin，Codex 用 `$` 选 Skill。不同版本、套餐和工作区显示的名称可能不一样，找不到也别慌。

开发者同学如果需要查机器上可用的 Plugin，跑下面这条命令就行。普通用户跳过，不用管：

```bash
codex plugin list --available --json
```

我自己的选择顺序是这样的，供你参考：

1. 优先用 ChatGPT / Codex 自带、有完整验证流程的文件类能力；
2. 需要连实时外部系统的时候，用官方或可信的 Plugin / MCP；
3. 社区 Skill 安装之前，审查源码、脚本、网络权限和许可证——这一步别偷懒；
4. 等工作流跑稳了，再考虑创建自己的 Skill；
5. 别为了"一句话生成"牺牲可编辑性、来源追溯和质量检查。AI 一口闷出来的东西，往往改起来更费劲。

## 通用任务开场模板

这个模板是我每次开新任务时用的，直接复制粘贴改一改就行。它能帮 AI 快速理解你要什么、不要什么，省很多来回沟通的时间：

```text
我要完成 [交付物]，用于 [受众/渠道]。

输入：
- [文件、数据、链接和素材]
- 其中 [来源] 是事实依据，[来源] 只作为风格参考

交付：
- 文件类型：[pptx/xlsx/pdf/mp4/site/...]
- 尺寸/时长：[要求]
- 必须包含：[内容]

边界：
- 不编造数字、引用、评价或产品能力
- 不使用无授权素材、商标、人物肖像或音乐
- 不发送、分享、上架、投放或发布

先给出生产计划和中间检查点。每完成一个阶段，提供可查看的产物和验证结果。
```

## 质量检查的四个层次

最后送你一个检查清单。每次 AI 交活之后，从这四个层次扫一遍，基本不会漏掉大问题：

1. **事实**：数据、名称、时间、规格和来源对不对。
2. **结构**：故事线、信息层级和用户流程清不清楚。
3. **文件**：格式能打开吗、元素能编辑吗、公式/链接/字幕都有效吗。
4. **发布**：版权、隐私、品牌、平台规则和人工审批都过了吗。
