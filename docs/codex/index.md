# Codex 教程

本教程面向希望使用 Codex 完成真实软件开发任务的开发者，帮助你从选择使用方式和第一次只读任务开始，逐步建立可复用、可验证的开发工作流。

## 学习路线

1. 安装 Codex App 或 Codex CLI。
2. 打开一个本地项目并完成第一次只读任务。
3. 使用 `AGENTS.md` 固化项目规则和验证命令。
4. 使用 Skills 复用工作流，使用 MCP 连接外部工具。
5. 在提交前运行测试并完成代码审查。

## 核心内容

- Codex App 安装与第一次打开项目
- Codex CLI 安装与常用命令
- `AGENTS.md` 使用教程
- Codex Skills 使用与创建
- Codex MCP 配置与安全边界
- 使用 Codex 做代码审查

需要配置 Codex 使用 CCWS 时，请查看 [CCWS Codex 配置文档](https://docs.ccws.pro/guide/codex)。
