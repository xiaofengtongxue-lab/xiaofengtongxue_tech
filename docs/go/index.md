# Go 技术教程

嘿，我是小枫同学 👋 欢迎来到我的 Go 小天地！

这一亩三分地是我写 Go 的实战笔记。不是什么高深的理论课，就是我在日常搬砖、做 side project 时踩过的坑、攒下的经验，整理出来给自己备忘，也顺便能帮到刚好路过的你。

## 我都会写点啥

- Go 项目结构与模块管理 —— 怎么把代码目录整得清清爽爽
- 接口、结构体和错误处理 —— 那些 Go 里绕不开的基本功
- Goroutine、Channel 和 Context —— 并发编程，Go 的真·灵魂
- HTTP 服务与中间件 —— 撸一个顺手的小服务出来
- 数据库访问与事务 —— 跟数据打交道的那点事儿
- 测试、基准测试和性能分析 —— 代码写完了，怎么证明它靠谱 + 快

这些是目前在计划里的，后面边写边加，反正常年施工中 🚧

关于跨项目的架构、发布流程那一套，我放在了 [工程实践](/engineering/) 那边，两边的文章互相呼应，可以串着看。
